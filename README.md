# 이메일 서명 생성기

(주)날리지포인트 메일 서명 HTML을 브라우저에서 생성하는 정적 웹앱입니다.

## 사용 방법

1. 좌측 폼에 이름, 직급, 연락처 등을 입력합니다.
2. **생성하기**를 누르면 우측 상단에 미리보기, 하단에 붙여넣기용 HTML이 표시됩니다.
3. **클립보드 복사**로 HTML을 복사해 메일 클라이언트 서명 설정에 붙여넣습니다.

## 로컬 실행

정적 파일이므로 아무 HTTP 서버로 열면 됩니다.

```bash
npx serve .
```
